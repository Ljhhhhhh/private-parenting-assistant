# PWA 安装提示优化

## 概述

本次优化调整了 PWA 安装提示的展示逻辑和位置，提升用户体验。

## 主要变更

### 1. 展示逻辑调整

**修改前：**

- PWA 安装提示在 `App.tsx` 中全局展示
- 用户一进入应用就可能看到安装提示

**修改后：**

- 移除了 `App.tsx` 中的全局 PWA 安装提示
- 只在用户登录到首页后才展示安装提示
- 提升了用户体验的连贯性

### 2. 位置调整

**修改前：**

- 安装提示显示在页面底部（`bottom-4`）
- 可能与底部导航栏冲突

**修改后：**

- 安装提示显示在页面顶部（`top-4`）
- 避免了与底部导航栏的冲突
- 增加了 `position` 属性支持自定义位置

### 3. 样式优化

**新增特性：**

- 使用设计规范中的主色调（`#4A90E2` 到 `#7AADEE` 渐变）
- 添加毛玻璃效果（`backdrop-blur-sm`）
- 优化了按钮样式，主按钮使用白色背景配合品牌色文字
- 添加优雅的滑入动画（`animate-slide-down`）

### 4. 动画增强

**新增动画：**

```css
@keyframes slide-down {
  0% {
    opacity: 0;
    transform: translateY(-20px);
  }
  100% {
    opacity: 1;
    transform: translateY(0);
  }
}

.animate-slide-down {
  animation: slide-down 0.5s ease-out;
}
```

## 代码变更

### App.tsx

- 移除了 `PWAInstallPrompt` 的导入和使用
- 简化了 App 组件的结构

### Home.tsx

- 导入 `PWAInstallPrompt` 组件
- 在首页顶部添加安装提示组件
- 使用 `position="top"` 指定顶部显示

### PWAInstallPrompt 组件

- 新增 `position` 属性支持 `'top' | 'bottom'`
- 优化样式使用设计规范色彩
- 增强视觉效果和用户交互体验

### animations.css

- 新增 `slide-down` 关键帧动画
- 新增 `.animate-slide-down` 工具类

## 用户体验提升

1. **时机优化**：只在用户登录后展示，避免打断登录流程
2. **位置优化**：顶部展示避免与底部导航冲突
3. **视觉优化**：符合品牌设计规范，视觉一致性更强
4. **动画优化**：流畅的滑入动画提升交互体验
5. **响应式适配**：在不同设备上都有良好的展示效果

## 技术特点

- **组件化设计**：可复用的 PWA 安装提示组件
- **灵活配置**：支持位置自定义和样式扩展
- **设计一致性**：使用统一的设计系统色彩和动画
- **性能优化**：按需加载，不影响应用启动速度
